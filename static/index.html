1. Mathematical Formulation: Min-Max Robust Optimization

AdvRoNIDS formalizes network intrusion detection as a saddle-point optimization problem against an adversary constrained to valid network semantics:

minθ 𝔼(x, y) ∼ D [ maxδ ∈ S L(fθ(x + δ), y) ]

where the domain-feasible perturbation set S is defined as:
S = { δ ∈ ℝd : ||δ||∞ ≤ ε, δF = 0, δC ≥ 0, padv ∈ Δk-1 }

2. Feasibility Projection Operator (ΠS)

In real-world networks, an attacker cannot arbitrarily manipulate all 71 flow features. The ΠS projection enforces three physical constraints:

  • 24 Frozen Protocol Invariants (δF = 0): Structural TCP flags (SYN, FIN, RST, PSH, ACK, URG), destination ports, and discrete packet metadata cannot be perturbed without breaking the connection.
  • 9 Cumulative Non-Decreasing Counters (δC ≥ 0): Packet counters and byte totals can only accumulate during a transmission, never decrease.
  • Discrete Protocol Simplex (padv ∈ Δk-1): Protocol type remains strictly mapped to one-hot vectors [TCP, UDP, ICMP].

3. Section 3.3 Scope Boundary Declaration

Explicit Research Boundary: AdvRoNIDS operates in the domain-constrained feature space using standardized network flow metrics from the CIC-IDS2017 benchmark. The ΠS operator ensures that computed adversarial trajectories respect protocol rules. This simulation does not perform live-wire raw socket sniffing or raw PCAP packet injection on personal network interfaces.
