1. Min-Max Adversarial Formulation

AdvRoNIDS formulates robust classification as empirical risk minimization against the worst-case domain-projected perturbation:
min_θ E_{(x,y)~D} [ max_{δ ∈ S} L(f_θ(x + δ), y) ]

2. Structural Domain Projection Operator (ΠS)

The projection operator ΠS ensures all generated feature perturbations conform to physical networking constraints:
(ΠS(x))i = xi ∀ i ∈ Ffrozen (Flags, Protocols, Port Bindings)
(ΠS(x))j = clip(xj, minj, maxj) ∀ j ∈ Fcontinuous
(ΠS(x))k ≥ xk ∀ k ∈ Fcumulative (Cumulative counters non-decreasing)

3. Section 3.3 Scope Boundary

AdvRoNIDS operates directly on standardized feature vectors derived from the benchmark CIC-IDS2017 dataset. In accordance with Section 3.3, packet modification is computed mathematically within the feature space without raw personal network packet sniffing.
